## Problem statement:
Finding best mortgage rates without disclosing my assets.

This project is for the flower hackathon. It should make use of the flower.ai infrastructure.

Bank Agent:
Each bank provides a mortgage rate based on income, mortgage value and house price.

User Agent:
The user provides their income, mortgage value and the house price to their agent. The user's agent then interacts with the bank agents and 

The key constraint in this is that the user's financial information should never be released to a bank. It can only be discussed within a closed forum between the agents.

Demo:
The demo should simulate 2 example banks offering different rates based on incomes. The user can input their information and receives a recommendation of what the best offer is.
